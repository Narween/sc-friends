Comment remplir / rafraîchir friends.db

Ces commandes se lancent dans un terminal, à la racine du projet — cette page ne les déclenche pas elle-même (elles ouvrent un vrai navigateur pour la connexion).

  1. node login.js — ouvre Chromium, tu te connectes à la main (2FA compris), la session est sauvegardée dans auth.json. …
  2. node fetch-friends.js — recharge auth.json et récupère la liste complète des amis dans friends.json. …
  3. node import-friends.js — charge friends.json dans friends.db (upsert : ne touche jamais aux décisions déjà prises). …
